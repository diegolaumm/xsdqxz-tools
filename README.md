# 新射雕群俠傳資源處理工具

這是一套我在研究《新射雕群俠傳之鐵血丹心》遊戲檔案時製作的資源處理工具。

最初是因為希望了解遊戲內的圖片與動畫資源如何儲存，因此開始研究遊戲檔案的結構，並逐步將不同的處理步驟整合成目前的工具。

本專案主要負責將 DDD3 格式的資料進行處理，並配合外部工具轉換 PKM 圖片；另外也包含將輸出的圖片重新組合為 GIF 動畫的功能。

> 本專案為個人研究與學習用途，不包含原遊戲之美術、音樂等資源。

---

## 功能

目前主要包含：

- DDD3 資料處理與輸出
- 串接 PKM 圖片轉換流程
- 遊戲圖片資源整理
- 根據輸出的連續圖片重新製作 GIF 動畫

---

## 使用前準備

### 1. 安裝 Python

本專案中的處理程式以 Python 執行，因此使用前需先準備 Python 環境及程式所需套件。

### 2. 準備 pkm2png

本專案的 PKM → PNG 轉換使用第三方工具
[zhukunqian/pkm2png](https://github.com/zhukunqian/pkm2png)。

該工具並非本人製作，本 repository 亦不包含其程式檔案。

使用本專案前，請先至原作者 repository 取得 `pkm2png`，
再依照自己的電腦環境設定相關檔案位置。

---

## 基本使用方式

### DDD3 資源處理

1. 修改 `GO.py` 最下方的檔案位置。
2. 將尚未處理的 DDD3 檔案放入 `input` 資料夾。
3. 執行 `GO.py`。
4. 完成前段處理後，使用另外下載的 `pkm2png` 執行 `pkm2png.bat`。
5. 至輸出資料夾查看轉換完成的資源。

---

## GIF 動畫還原

若需要將遊戲中的連續圖片重新組合為 GIF：

1. 開啟 `run` 資料夾。
2. 進入 `GIF` 資料夾。
3. 開啟 `test.py`。
4. 修改程式最下方的檔案位置，使其指向前面處理後產生的圖片。
5. 執行 `test.py`。
6. 查看輸出的 GIF 動畫。

---

## 專案限制

目前這套工具主要是依照我自己的研究環境製作，因此仍有一些限制：

- 部分檔案路徑需要手動修改。
- PKM → PNG 功能依賴外部的 `pkm2png`。
- 尚未製作統一的圖形化操作介面。
- 不同電腦環境可能需要另外調整路徑與 Python 套件。

因此目前比較接近一套研究過程中逐步建立的處理工具，而非下載後即可直接使用的完整應用程式。

---

## 關於本專案

這個專案不只是為了取得遊戲資源。

在研究過程中，我嘗試理解不同檔案格式、尋找可以處理特定格式的既有工具，並將不同處理方式串接成可以實際運作的流程。

部分程式碼的撰寫與除錯過程使用了 AI 工具協助；我主要負責研究問題、設計處理流程、測試結果、調整需求，以及將不同工具與處理步驟整合成目前的形式。

本 repository 僅作為個人學習、研究及作品展示使用，不提供原遊戲檔案或遊戲中的美術、音樂等資源。
